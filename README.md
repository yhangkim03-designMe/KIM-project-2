# KIM-project-2 — Kabankalan Catholic College website

A responsive multi-page college website built from the supplied KCC HTML files and images.

## Preview locally
1. Extract/open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Navigate using the menu at the top of each page.

## Included pages
- `index.html` — Home
- `about.html` — About KCC
- `courses.html` — Academic Programs
- `course-details.html` — Program Information
- `events.html` — Campus Life & Events
- `trainers.html` — Faculty & Staff
- `pricing.html` — Admissions & Enrollment
- `contact.html` — Contact
- `starter-page.html` — Additional information

## Images
The supplied KCC images are in `assets/img/`. Styles are in `assets/css/style.css`.
The site uses a responsive custom stylesheet and does not require local Bootstrap vendor files.

## Before publishing
Please verify the official program list, admission requirements, tuition/fees, school contact details, and faculty directory with Kabankalan Catholic College. Unverified names, prices, phone numbers, emails, and dates have deliberately not been invented.

## Git and GitHub Pages
Initialize and commit your work locally, then create a public GitHub repository named `KIM-project-2`. Push the `main` branch and enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
